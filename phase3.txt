# PHASE 3 — WEB FRAMEWORK CORE (LARAVEL-LIKE)

Sekarang lanjutkan NgapakIn menjadi framework web seperti Laravel versi Ngapak.

Fokus:

* router
* request
* response
* controller
* middleware
* template engine
* service container

Jangan membuat ORM dulu.

Buat struktur framework seperti Laravel:

app/
├── Controllers/
├── Middleware/
├── Services/

routes/
├── web.ngpk
├── api.ngpk

resources/
├── views/

framework/
├── router.py
├── request.py
├── response.py
├── controller.py
├── middleware.py
├── container.py
├── view.py
└── template_engine.py

Fitur router:

rute.get("/", "HomeController@index")
rute.post("/login", "AuthController@login")

rute.group(["middleware": "auth"], gawe()
rute.get("/dashboard", "DashboardController@index")
rampung)

Fitur:

1. Route GET/POST/PUT/DELETE
2. Route parameter
3. Route group
4. Middleware
5. Request object
6. Response object
7. JSON response
8. Redirect helper
9. Controller loader
10. Service container sederhana

Template engine `.nview`

Contoh:

<html>
<body>

<h1>{{ title }}</h1>

@nek user <p>Halo {{ user.name }}</p>
@liyane <p>Login dulu</p>
@rampung

</body>
</html>

Fitur template:

* {{ variable }}
* @nek
* @liyane
* @baleni
* @include
* @layout
* @section
* @yield

CLI:

python ngapakin.py serve
python ngapakin.py route:list
python ngapakin.py make:controller HomeController
python ngapakin.py make:middleware AuthMiddleware
