# PHASE 1 — CORE LANGUAGE ENGINE

Saya ingin membuat Phase 1 dari project open-source bernama NgapakIn.

NgapakIn adalah bahasa pemrograman dengan ekstensi `.ngpk`.

Phase 1 fokus hanya pada core language engine.

Jangan membuat framework web dulu.
Jangan membuat ORM dulu.
Jangan membuat migration dulu.
Jangan membuat auth dulu.

Fokus hanya pada:

* lexer
* parser
* AST
* interpreter
* environment scope
* CLI

Tech stack:

* Python 3
* Clean architecture
* Modular
* Scalable

WAJIB menggunakan:

* lexer
* parser
* AST
* interpreter

Jangan membuat interpreter sederhana menggunakan:

* startswith
* split biasa
* eval langsung
